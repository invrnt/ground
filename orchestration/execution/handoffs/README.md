# Implementation handoffs

No implementation agents have run yet. This folder will receive `<agent-name>.md` from each agent when its assignment is complete. A handoff is evidence of what happened, not a promise that later work is done.

Include:

- Agent, stage, branch/worktree and base/result commits.
- Owned changes and completed requirements.
- Exact commands or manual checks, outcome and any untested behavior.
- Configuration variable names, pinned versions and verified provider signatures, without secret values.
- Redacted evidence, source links, remote IDs where appropriate, and unresolved blockers.
- Latest reviewed `FEEDBACK.md` content hash/time and applied/deferred notes, if present.
- For the shared owner: registrations, merged green stage commit and full stage gate outcome.

The release handoff also names live rehearsal evidence, deferred measurement work and final GitHub PR review outcome supplied by the Orchestrator. Preserve individual ownership of these files.
